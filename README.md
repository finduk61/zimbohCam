# zimbohCam

iPhone Safari'de çalışan, ana ekrana eklenebilen film kamerası.

- **Kamera modu:** canlı film efektli vizör, lens seçimi (13 / 24 / 48 / 120mm), film rulosu
- **Düzenle modu:** ProRAW (DNG) ve galeri fotoğraflarını film görünümüyle işleme, 1:1 inceleme, tam çözünürlükte kaydetme
- **Presetler:** Cinestill 800T, Portra 400, Tri-X 400, Fuji Superia 400, Ektachrome E100 + kendi presetlerin

Kurulum: bu klasörün içeriğini bir GitHub deposuna yükle, Settings → Pages → Branch: `main` → Save.
Sonra `https://KULLANICIADI.github.io/zimbohCam/` adresini iPhone'da Safari ile aç → Paylaş → Ana Ekrana Ekle.

Fotoğraflar ve presetler yalnızca telefonda saklanır, hiçbir sunucuya gönderilmez.
